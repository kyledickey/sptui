Spotify in your terminal.

A fast, keyboard-driven Spotify player, that doesn't slow down your computer.

install
curl -fsSL https://sptui.sh/install.sh | bash
irm https://sptui.sh/install.ps1 | iex

or build it yourself, with Go

brew install libogg libvorbis flac mpg123
go install github.com/kyledickey/sptui/cmd/sptui@latest
sudo pacman -S libogg libvorbis flac mpg123 alsa-lib
go install github.com/kyledickey/sptui/cmd/sptui@latest
sudo apt install libogg-dev libvorbis-dev libflac-dev libmpg123-dev libasound2-dev
go install github.com/kyledickey/sptui/cmd/sptui@latest
# in MSYS2's UCRT64 shell
pacman -S mingw-w64-ucrt-x86_64-{go,gcc,pkgconf,libogg,libvorbis,flac,mpg123}
go install github.com/kyledickey/sptui/cmd/sptui@latest

Then run sptui. Needs Spotify Premium.

What it does

  • Spotify Connectshows up as a device, so your phone can drive it
  • Synced lyricsscroll along with the song
  • Radio and DJ Xstart a station from a song, or let the DJ pick
  • Album artreal images in kitty and Ghostty, pixels everywhere else
  • Podcastsshows how far you got in each episode
  • Offline cacheopens instantly, and keeps working when Spotify is busy
